📦 文档模块生成器

本地运行 · 零依赖 · 生成后把文件夹丢进 src/extensions/ 即可

模块总单

← 左侧选择一个模块，或点「＋ 新建模块」
每篇 = 左侧一个目录项，标题下用 # 一级标题 分小节
⬇ 导出完整模块（生成 meta.ts + data.ts）

生成的文件夹结构：

src/extensions/模块标识/
├─ meta.ts      ← 自动生成（模块注册信息）
└─ data.ts      ← 自动生成（你写的全部文档）

把下载的两个 .ts 文件放进 src/extensions/模块标识/ 文件夹，刷新网页即生效，不需要写代码、不需要后端。
