一、项目概览

闪传是一款免安装、跨平台的大文件传输工具，文件全程经端到端加密（E2EE），服务器/中转方只经手密文。核心价值：

  • 三种传输模式：中转（tus）、本地直传（HTTP 中继）、P2P 直连（WebRTC），前端分 Tab 切换，按需选链路。
  • 统一加密帧：三条链路共用同一字节级帧格式，解析逻辑共享、互不干扰。
  • 纯前端 + 零外网依赖：Vue3 + TypeScript + Vite 构建，无 CDN、无第三方运行时，可完全离线部署。
  • 大文件友好：中转 20GB 不爆内存；直传/P2P 背压流式边收边写、支持 seek 续传。

三、中转 tus 架构（核心）

中转链路是当前工程最复杂、踩坑最深的部分。架构主线：浏览器本地加密 → 切网络块 → 拿预签名 URL → 浏览器直传 R2 → commit 确认。Worker 只发 URL、不碰字节流。

中转链路关键决策（勿重犯）

事项结论
Workers R2 binding 无 createPresignedUrl改用官方 aws4fetch 走 S3 兼容签名
自动部署不读 Dashboard 手填变量凭证必须写 wrangler.toml [vars]
wrangler.toml R2 凭据必须与 Dashboard 官方值逐字符一致（曾漏 b0 段致 403）
SignatureDoesNotMatch勿手动 set X-Amz-Expires，用 aws.expires 选项
中转「假完成」tus 指纹不含 transferId + E2EE Blob 无 name → 退化撞车，已删 resume
